How to choose

Start with the source if you know it. A burst pipe, a failed water heater and a leaking dishwasher have their own pages. If the water came from outside, see storm, flood or basement. If it came up through a drain, see sewage backup.

If you only know what is wet, start with the material. Walls, ceilings, carpet and hardwood each have pages. For a general question about how drying works, read structural drying and water extraction.

Businesses should read the commercial water damage page. If you suspect mold after a leak, read mold remediation and testing. For any active leak, call (636) 747-8964 first and read second.

ANSI/IICRC S500 is the published standard for professional water damage restoration, and S520 covers mold remediation. This page names them as references only, so you can compare any plan you receive against the same yardstick.
